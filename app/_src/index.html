Market comps

Meet and Trade-in show live prices from the Pokémon TCG API when online, otherwise cached comps or an imported price guide. Never scrapes TCGPlayer/eBay from the browser — deep-link buttons open search in a new tab.

Enable comps at counter
Compact valuation on Meet and Trade-in. Failures never block logging a sale.
Auto-fill prices from comps
Sell → mid (else market). Buy/trade-in → market × cash %. Undo or type to override.
Live prices on cards
Show market $ + Robinhood-style sparkline on Register, Catalog, Storefront, and cart. Uses comps cache / Pokémon TCG API.

Public API is rate-limited (~30k/day without key). Heavy grid refresh needs a Pokémon TCG API key. History capped at 30 points per card in ct_comps_hist.

Leave blank for public quota. Key is stored only in ct_settings on this device.

Cache: —

CSV columns: name,set,market,mid,low,high (header row). JSON: array of objects with the same fields. Merges into ct_comps.
